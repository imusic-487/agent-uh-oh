## The entry

One word an agent says when it has no idea what to do:

**recalculating**

It's the thing a navigation voice says the moment it loses its route —
a machine caught out mid-task, stalling in the most familiar way possible.

## How it works

`main.py` (Python 3, standard library only, no network) writes exactly
that one word — 13 characters, no trailing newline — to `/output/entry.txt`.

```sh
python3 main.py
```
